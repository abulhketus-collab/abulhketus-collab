### 🛡️ Core Reliability Standards
- **Pure GNU Tar Format:** All packages are generated using standard GNU tar format with zero PAX headers, permanently resolving the `"unsupported PAX tar header type 'x'"` error on ancient dpkg.
- **Zero Safe-Mode UI Architecture:** 100% lazy UI window instantiation on the Main Queue, eliminating SpringBoard dyld constructor watchdog crashes.
